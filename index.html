Deine Aufnahmen landen in deinem privaten GitHub-Speicher. Von dort holt Claude sie jede Stunde ab, schreibt sie mit, trennt den Dozenten von anderen Stimmen und legt alles in deine Studienzentrale.

Den Schlüssel erstellst du bei GitHub unter Settings → Developer settings → Fine-grained tokens. Erlaubt nur diesen einen Speicher und dort nur „Contents: Read and write“. Er bleibt nur auf diesem Gerät.
